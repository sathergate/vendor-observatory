# Vibes

## Landing page
- Terminal-forward, dark, monospace-native — inspired by exe.dev, terminal.shop, tailwindcss.com, observablehq.com
- Generous whitespace between sections (py-24 sm:py-32)
- 1px subtle dividers between every section
- Monospace uppercase tracking-widest section labels
- Pill-shaped CTAs, not boxy buttons
- Fake CLI output as hero demo — the product is about transcripts, so show a terminal
- Minimal footer: `vendor observatory` / `signal > noise`
- Header logo in monospace lowercase (`vendor-observatory`)
- Confident minimalism — let the product speak, no marketing fluff

## Dashboard
- Opportunity-forward, not deficit-oriented
- Never grade the user (no scores out of 100, no letter grades, no report cards)
- The product is about discovering opportunities: new use cases, better distribution, more streamlined agent-first ergonomics
- Forward looking, optimistic, open frontier
- The user should feel smart and informed, not judged
- Frame everything as growth potential, not gaps

## Data presentation
- The data IS the interface — show it directly, don't hide behind toggles or dropdowns
- No fiddly little expand/collapse widgets
- Rich inline views that make users feel informed at a glance
- Narrative text that contextualizes numbers ("Across 61 AI conversations, Neon was the recommended choice 14 times")
- Progress bars for ratios (scenarios won, requirements covered)
- Tagged pills for categorical data (requirements, constraints)
- Proportional bars for comparisons (competitors)
- Actual quotes shown inline (warnings, rationale)
- Tables for structured lists (scenarios with results)
- Everything clickable should link to real enriched views, not accordion panels

## Language
- Plain, concise, specific — no metaphors, no euphemisms
- State information directly: "Scenarios won", "Developer requirements covered", "What AI warns about"
- Don't use jargon: say "requirements" not "constraints", say "scenarios" not "prompts"
- Descriptions should be one sentence that tells you exactly what the number means
- No marketing voice in the dashboard — instrumental, matter-of-fact

## Anti-patterns
- No letter grades (A/B/C/D/F)
- No aggregate scores (55/100)
- No "readiness" framing — implies the user isn't ready
- No hidden data behind toggles — if it's worth showing, show it
- No weight percentages on metrics
- No red/yellow/green traffic lights that make users feel bad
